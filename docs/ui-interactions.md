# 《小说佳》界面与交互细化（UI/UX Spec）

## 1. 页面：开始创作（核心）
### 1.1 总体布局（左右分栏）
- **左侧：章节目录区**
  - 顶部工具：新建章节、导入、导出、搜索（可选）
  - 中部列表：章节项（序号、标题、状态、字数）
  - 底部状态：当前项目名、存储位置、自动保存状态（可选）
- **右侧：内容编辑区**
  - 顶部：章节标题（可编辑）、状态徽标（草稿/已提交）、字数
  - 工具条：AI润色、回溯阅读、确认保存（提交）
  - 主体：编辑器
  - 底部：下一章节预告（提交后出现/填充）

### 1.2 关键交互流程

#### 流程A：新建章节并开始写作
- 触发：点击“新建章节”
- 结果：
  - 左侧新增章节项（默认标题“第X章”）
  - 右侧加载空白编辑器并聚焦输入
  - 自动保存启用（默认）

#### 流程B：切换章节
- 触发：点击左侧章节项
- 前置条件：当前章节存在未保存草稿
- 行为：
  - 若自动保存开启：切换前先自动保存草稿
  - 若自动保存关闭：弹窗提示【保存/不保存/取消】
- 结果：右侧加载目标章节内容；工具条与预告区域随章节切换刷新

#### 流程C：AI润色（选中/全文）
- 触发：点击“AI润色”
- 交互：
  - 若存在选中文本：默认润色选中；提供切换“润色全文”
  - 进入请求中状态：按钮置灰，显示“生成中…”，可取消（可选）
  - 返回结果后进入对比应用面板（建议默认）：
    - 左：原文（只读）
    - 右：润色后文本（只读）
    - 操作：应用替换 / 插入到光标 / 复制 / 放弃
- 失败：
  - 鉴权失败：提示去“设置-API密钥”配置
  - 限流/超时：提示重试并保留当前输入不丢

#### 流程D：回溯阅读（帮助保持脉络）
- 触发：点击“回溯阅读”
- 展示：不打断编辑的侧栏/抽屉（建议）
- 默认内容：
  - 上一章原文快速浏览（只读）
  - 上一章摘要（若已缓存则直接展示；否则触发AI摘要并缓存）
- 操作：
  - 选择回溯范围：上一章/前N章/全书摘要（至少提供上一章）
  - 一键插入“关键信息提示”到编辑区（可选）

#### 流程E：确认保存（提交）
- 触发：点击“确认保存”
- 校验：
  - 内容为空：提示确认（允许提交空章但需二次确认）
  - 章节标题为空：自动回填默认标题或提示
- 提交流程：
  - 生成版本快照（用于对比/回滚）
  - 章节状态置为“已提交”，记录提交时间
  - 自动触发“下一章节预告生成”

#### 流程F：提交后生成下一章节预告（可编辑）
- 触发：章节提交成功后自动触发
- 展示：
  - 预告区域显示“生成中…”
  - 生成完成后填入文本框（可编辑）
- 操作：
  - 保存预告
  - 重新生成（可选）
  - 应用为下一章提示/大纲（可选）

### 1.3 控件灰态/空态
- 未选章节：编辑器显示空态文案 + 引导“新建章节”
- AI调用中：相关按钮禁用，避免重复请求
- 无上一章：回溯阅读展示“暂无可回溯章节”

## 2. 页面：智能体模式（进阶）
### 2.1 入口与模式提示
- 入口：顶部Tab或开关
- 进入提示：
  - 将读取全书内容（可选包含草稿）
  - 可能耗时/消耗token（如适用）

### 2.2 智能体操作面板（建议结构）
- 目标选择：
  - 风格统一/语言润色（全局）
  - 逻辑一致性修复（矛盾、时间线、设定）
  - 节奏与可读性优化
- 范围选择：
  - 全书 / 多选章节 / 仅已提交章节 / 包含草稿（勾选）
- 输出模式：
  - 仅给建议（不改正文）
  - 生成改动清单（默认）

### 2.3 改动记录清单：审阅与应用
- 列表项字段（展示）：
  - 章节、位置、改动类型（替换/插入/删除）、原因
  - Before/After（支持展开）
- 操作：
  - 单条：应用 / 跳过
  - 批量：全选应用 / 全部跳过
  - 安全：应用前自动创建“项目快照”
  - 回滚：一键回滚到应用前快照

## 3. 通用交互规则
- **撤销/重做**：编辑器内支持；智能体应用支持“整体回滚”
- **错误提示**：所有AI错误需落到可操作提示（去设置/重试/稍后）
- **加载体验**：AI输出建议支持流式展示（可选）提升体感
