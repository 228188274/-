# 《小说佳》本地小说创作软件需求说明（PRD/SRS）

## 1. 产品概述
- **产品名称**：小说佳
- **运行形态**：本地电脑运行（Local-first），默认不依赖云端存储
- **核心定位**：以“降低创作门槛、提升创作效率”为目标，提供“AI辅助 + 作者主导”的小说创作工具
- **AI集成**：支持对接 **DeepSeek**、**智谱（GLM）** 等API（可扩展）
- **核心原则**
  - **作者主导**：AI仅辅助，所有落盘内容必须可追溯、可撤销、可对比
  - **数据安全**：小说内容与结构默认仅存本地；API密钥本地安全存储
  - **可控可解释**：智能体批量修改必须输出可核对的“改动记录清单”

## 2. 目标用户与典型场景
- **目标用户**
  - 初学写作者：需要降低构思、表达门槛
  - 有连载/长篇经验作者：需要章节管理、风格一致性、批量修订
- **典型场景**
  - 从本地已有文档导入（接续创作）
  - 章节创作过程中进行润色、回溯阅读
  - 提交章节后自动生成下一章预告
  - 启用智能体对全书统一优化并输出改动清单

## 3. 信息架构（导航/模块）
> 本文以“开始创作”为核心模块展开；其他模块可作为后续扩展。

- **开始创作（核心）**
  - 章节目录管理区（左侧）
  - 内容创作编辑区（右侧）
  - 章节提交后“下一章节预告”（右侧下方）
- **智能体模式（进阶）**
  - 全章节阅读理解
  - 批量优化
  - 改动记录清单输出（可回放/可应用/可撤销）
- **设置/密钥管理**
  - DeepSeek/智谱 API Key 配置与测试
  - 模型选择、参数（温度、最大输出等）与提示词模板管理（可选）

## 4. 功能需求（Functional Requirements）

### 4.1 开始创作：左右分栏布局
#### 4.1.1 左侧：章节目录管理区
- **FR-001 章节目录展示**
  - 展示当前作品的章节树/列表：章节序号、标题、字数、最后修改时间、状态（草稿/已提交）
  - 支持按章节快速定位：点击章节后右侧加载对应内容
  - 支持搜索/过滤（可选）：按标题、关键词

- **FR-002 新建/重命名/删除章节（基础编辑）**
  - 新建章节：默认命名“第X章”
  - 重命名章节：即时校验重名冲突（允许同名但提示，或禁止同名——需在产品策略中固定）
  - 删除章节：必须二次确认；删除进入回收站（可选）或可撤销（建议保留30天或按项目设置）

- **FR-003 文件导入（接续创作）**
  - 导入来源：本地文件
  - 最低支持格式：`txt`、`md`
  - 可选支持：`docx`（如引入解析库）
  - 导入策略：
    - **整本导入**：按“章节分隔规则”拆分生成目录（如 `第.*章` 正则；或用户手动选择分隔符）
    - **单章导入**：导入为当前选中章节内容（覆盖/追加可选）
  - 导入完成后生成导入报告：章节数、失败条目、字符编码识别结果

- **FR-004 文件导出**
  - 导出范围：整本 / 选中章节 / 多选章节
  - 导出格式：`txt`、`md`（最低）
  - 导出选项：
    - 是否包含目录
    - 章节标题格式（如 `# 第1章 标题`）
    - 换行风格（Windows/Unix）可选
  - 导出后提示保存位置与文件名规则（作品名_日期等）

#### 4.1.2 右侧：内容创作编辑区
- **FR-005 章节内容编辑**
  - 支持基础富文本或Markdown编辑（实现方式可选，但需保证导出一致）
  - 自动保存草稿（建议默认开启）：如每10秒或编辑停顿2秒触发
  - 显示字数、段落数、预计阅读时长（可选）

- **FR-006 AI润色按钮（当前输入内容润色）**
  - 触发范围：当前章节全文 / 选中文本（建议两种都支持）
  - 产出要求：返回润色结果，并提供三种落地方式：
    - **替换原文**
    - **插入到光标处**
    - **并排对比后应用**（建议默认，减少误改）
  - 失败处理：网络错误、鉴权失败、限流时给出可理解提示与重试

- **FR-007 章节内容回溯阅读按钮**
  - 目标：快速回顾已创作内容，避免跑偏
  - 能力：
    - 回溯范围：上一章/前N章/全书摘要（至少提供上一章）
    - 展示形式：弹窗/侧栏/下拉面板（不打断编辑为优）
    - 内容形式：原文快速浏览 + 关键摘要（摘要可由AI生成，需可缓存）

- **FR-008 确认保存（章节提交）按钮**
  - 提交含义：将当前章节状态置为“已提交”，并记录提交时间与版本
  - 提交前校验：
    - 内容为空提示（允许强制提交但需确认）
    - 未保存草稿自动先保存
  - 提交后动作：
    - 触发 **FR-009 下一章节预告生成**
    - 生成一个“章节版本快照”，供后续智能体修改对比与回滚

### 4.2 章节提交后：下一章节预告（自动生成 + 可编辑）
- **FR-009 自动生成下一章节预告**
  - 触发时机：章节提交成功后自动触发
  - 输入上下文：
    - 当前章节内容（必选）
    - 前N章摘要/关键设定（可选但建议）
    - 角色/大纲信息（如未来扩展模块存在）
  - 输出要求：
    - 预告文本建议包含：核心冲突推进、关键人物动机、一个悬念点、下一章目标
    - 语言风格与当前作品一致（尽可能）

- **FR-010 预告可手动修改与保存**
  - 作者可直接编辑预告内容
  - 保存策略：
    - 与章节绑定（建议绑定“已提交章节 -> 下一章预告”）
    - 版本化保存（可选）
  - 可一键“应用为下一章大纲/开头提示词”（可选）

### 4.3 智能体模式（进阶：全章节统筹优化）
- **FR-011 进入/退出智能体模式**
  - 入口：手动切换（按钮/开关）
  - 进入前提示：将读取全书内容并可能产生较大token消耗（如适用）
  - 退出后不影响已保存内容

- **FR-012 智能体全章节阅读理解**
  - 读取范围：当前作品所有章节（含草稿/已提交的策略需固定；建议默认读“已提交”，可勾选包含草稿）
  - 产出：全书结构摘要、人物表、伏笔/冲突线索列表（可选，但推荐用于后续一致性优化）

- **FR-013 批量调整优化（按目标驱动）**
  - 支持目标类型（至少三类）：
    - 风格统一/语言润色（全局）
    - 逻辑一致性修复（时间线、人物设定、前后矛盾）
    - 节奏与可读性优化（段落、对话比例、信息密度）
  - 修改粒度：可按章节选择、可设置“仅建议不落盘”

- **FR-014 输出改动记录清单（强制要求）**
  - 智能体产生任何修改时，必须输出可核对的改动记录清单：
    - 修改位置：章节ID/章节标题/段落索引/字符范围（尽可能精确）
    - 原内容（Before）
    - 修改后内容（After）
    - 修改原因（Why）：一句话说明
  - 展示与应用：
    - 支持逐条“应用/跳过”
    - 支持一键“全部应用/全部撤销”
    - 支持对比视图（Before/After）

- **FR-015 回滚与版本管理（建议必做）**
  - 任何批量应用前自动创建“项目快照”
  - 支持回滚到快照（至少支持回滚最近一次智能体批量应用）

## 5. 数据与存储（建议方案）
### 5.1 本地数据结构（概念模型）
- **Project（作品）**
  - `id`、`title`、`createdAt`、`updatedAt`
  - `settings`（模型选择、提示词模板、导出偏好等）
- **Chapter（章节）**
  - `id`、`projectId`、`index`、`title`
  - `content`、`wordCount`
  - `status`：`draft` / `submitted`
  - `versions[]`：提交/快照版本列表
  - `nextChapterPreview`：与当前章节绑定的“下一章预告”
- **AgentRun（智能体运行记录）**
  - `id`、`projectId`、`createdAt`
  - `scope`（章节范围）
  - `goal`（优化目标）
  - `changeList[]`（改动记录清单）
  - `applied`（是否已应用到正文）

### 5.2 存储要求（非实现限定）
- 本地文件/数据库均可（如 SQLite / JSON 文件夹结构）
- 必须支持备份与迁移：导出项目包（建议 `zip`）

## 6. AI对接需求（DeepSeek/智谱）
- **FR-016 API密钥管理**
  - 支持配置多个提供方：DeepSeek、智谱
  - 密钥本地安全存储（见 NFR-004）
  - 提供“连通性测试”按钮：返回模型列表或简单回复

- **FR-017 模型与参数选择（最小可用）**
  - 每个能力点可选择模型（润色/预告/智能体）
  - 参数最少包含：温度、最大输出、是否流式输出（可选）

- **FR-018 提示词模板（可选但推荐）**
  - 内置模板：润色、回溯摘要、下一章预告、全书一致性修复
  - 支持用户自定义与重置默认

## 7. 非功能需求（Non-Functional Requirements）
- **NFR-001 本地优先与可离线**
  - 不调用AI时，核心编辑/章节管理/导入导出必须完全离线可用

- **NFR-002 性能**
  - 100章、每章1万字规模下，章节切换与搜索应保持可用（具体阈值可在实现阶段压测明确）

- **NFR-003 稳定性**
  - 异常退出不应导致已保存内容丢失（依赖自动保存与事务化写入）

- **NFR-004 安全**
  - API Key 不得以明文方式暴露在导出内容中
  - 建议：使用系统密钥链/加密存储（实现因平台不同可有差异，但需达成“非明文落盘”的验收）

- **NFR-005 可追溯**
  - 智能体批量修改必须可回滚；所有AI生成/修改均应记录来源与时间

## 8. 关键交互与界面约束（文本版）
### 8.1 “开始创作”布局
- **左栏**：章节目录（支持滚动、搜索、导入/导出入口）
- **右栏上部**：编辑器（章节标题、状态、字数、编辑区）
- **右栏工具条**：
  - AI润色
  - 回溯阅读
  - 确认保存（提交）
- **右栏下部**：下一章节预告区域（提交后自动填充，可编辑、可保存）

### 8.2 灰态/禁用状态（建议）
- 未选择章节时：编辑区与“提交”禁用，提示先选章节或新建章节
- 正在调用AI时：显示进度/可取消（可选），避免重复点击

## 9. 验收标准（Acceptance Criteria）
- **AC-001** 新建章节后可编辑内容，自动保存草稿，重新打开应用内容不丢失
- **AC-002** 点击“确认保存”后章节状态变为已提交，并生成一条版本快照
- **AC-003** 提交后自动生成“下一章节预告”，且作者可编辑并保存
- **AC-004** “AI润色”可对选中或全文生效，并支持对比后应用
- **AC-005** “回溯阅读”可查看上一章（至少）内容或摘要，不打断当前编辑
- **AC-006** 智能体模式下可读取全书并输出改动记录清单；改动可逐条应用/撤销
- **AC-007** 导入 `txt/md` 后可按章节规则生成目录；导出可生成 `txt/md` 文件
- **AC-008** API Key 配置后可测试连通；密钥不以明文出现在项目导出文件（或提供“导出不包含密钥”机制）

## 10. 范围边界（本版本不做/可后续做）
- 多人协作/在线同步（非核心，且与本地优先冲突）
- 公共素材云库
- 复杂排版（如专业出版社排版）与EPUB/MOBI（可后续扩展）
